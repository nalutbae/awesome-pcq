# 배선 가이드 (Wiring Guide)

> PCQ 실기시험에서의 PLC 배선 핵심 가이드입니다.

## 1. COM 단자 배선 (소스/싱크 타입)

XGB 시리즈 PLC의 디지털 입력은 소스(Source) 타입과 싱크(Sink) 타입을 COM 단자 배선에 따라 선택할 수 있습니다.

### 소스 타입 (Source)

```
    +24V ──┬── P0000 ──┐
           │           │
           ├── P0001 ──┤
           │           │
    COM ───┘           │
                       │
    PLC 입력 ──────────┘
```

- **특징**: 입력 단자에 +24V를 인가하여 ON
- **COM 배선**: COM 단자를 0V(GND)에 연결
- **용도**: PNP 타입 센서와 호환

### 싱크 타입 (Sink)

```
    0V ──┬── P0000 ──┐
         │           │
         ├── P0001 ──┤
         │           │
    COM ─┘           │
                     │
    PLC 입력 ────────┘
```

- **특징**: 입력 단자를 0V에 연결하여 ON
- **COM 배선**: COM 단자를 +24V에 연결
- **용도**: NPN 타입 센서와 호환

### ⚠️ 시험 주의사항

> PCQ 시험에서는 **소스 타입**이 일반적으로 사용됩니다. 하지만 문제의 I/O List와 배선도를 반드시 확인해야 합니다. COM 배선 방향에 따라 동작이 반전되므로, 배선 전 반드시 회로도를 확인하세요.

## 2. 출력 배선

### 릴레이 출력 (XBC-DR32H)

```
    내부 회로
    ──┬── COM0 (공통단)
      │
      ├── P0020 ── 부하 ── 전원
      │
      ├── P0021 ── 부하 ── 전원
      │
      └── COM0 ── 전원
```

- **릴레이 출력은 소스/싱크 구분 없음** (a접점)
- **COM 그룹 확인**: 8점 단위로 COM 단자가 분리됨 (COM0, COM1)
- **정격 부하**: DC24V 2A / AC220V 2A

### 트랜지스터 출력 (XBC-DN32H)

```
    내부 회로 (싱크 타입)
    ──┬── P0020 ── 부하 ── +24V
      │
      ├── P0021 ── 부하 ── +24V
      │
      └── COM0 ── 0V
```

- **트랜지스터 출력은 싱크 타입** (XBC-DN32H 기준)
- **COM0 배선**: 0V(GND)에 연결
- **정격 부하**: DC24V 0.5A
- **고속 출력**: 100kHz (APM 사용 시)

## 3. 전원 배선

### AC 전원 모델 (XBC-DR32H)

| 단자 | 연결 | 주의사항 |
| --- | --- | --- |
| L | AC 100~240V | 정격 전압 확인 필수 |
| N | 중성선 | — |
| G | 접지 | 3종 접지 (100Ω 이하) |

### DC 전원 모델 (XBC-DR32H/DC)

| 단자 | 연결 | 주의사항 |
| --- | --- | --- |
| + | DC 24V | 극성 주의 |
| - | DC 0V | — |
| G | 접지 | 3종 접지 (100Ω 이하) |

## 4. 접지

| 항목 | 규격 |
| --- | --- |
| 접지 종류 | 3종 접지 |
| 접지저항 | 100Ω 이하 |
| 접지선 굵기 | 2㎟ 이상 |
| 접지 방법 | 전용 접지 권장 (공용 접지 시 오동작 가능) |

> **주의**: 접지에 따라 오동작하는 경우 접지를 분리할 수 있습니다. 단, 안전상 접지 분리는 최후의 수단입니다.

## 5. 인버터 배선 (3급 과제 3)

PCQ 3급 시험의 3과제에서 인버터 배선 및 RS-485 통신이 출제됩니다.

### RS-485 통신 배선

| PLC 측 | 인버터 측 | 비고 |
| --- | --- | --- |
| RDA | RDA | 데이터 수신 |
| RDB | RDB | 데이터 수신 |
| SDA | SDA | 데이터 송신 |
| SDB | SDB | 데이터 송신 |
| SG | SG | 신호 접지 |

### 인버터 파라미터 주요 항목

| 파라미터 | 설명 | 설정 예 |
| --- | --- | --- |
| 통신 속도 | Baud rate | 9600 bps |
| 통신 프로토콜 | Modbus RTU 등 | LS 전용 프로토콜 |
| 국번 | Station ID | 1번 (설정값) |
| 운전 명령 | 통신/단자 | 통신 (PLC 제어) |
| 주파수 지령 | 통신/단자 | 통신 (PLC 제어) |

## 6. 배선 체크리스트

### 시험 시작 전

- [ ] I/O List와 PLC 접점 매칭 확인
- [ ] COM 단자 배선 방향 (소스/싱크) 확인
- [ ] 전원 전압 및 극성 확인 (AC vs DC)
- [ ] 접지 연결 확인
- [ ] 출력 COM 그룹 분리 확인 (COM0, COM1)

### 배선 완료 후

- [ ] 단자대 조임 상태 확인 (규정 토크)
- [ ] 배선 경로 정리 (노이즈 방지)
- [ ] 회로도와 실제 배선 대조
- [ ] 입력 스위치 동작 확인
- [ ] 출력 램프/모터 동작 확인
- [ ] 통신 배선 확인 (3과제: RS-485)

### 시험 종료 전

- [ ] 프로그램 다운로드 확인
- [ ] 시뮬레이터 또는 실물 테스트
- [ ] 타임차트와 실제 동작 비교
- [ ] 감점 요인 사전 점검
