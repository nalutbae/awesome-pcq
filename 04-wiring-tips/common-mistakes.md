# 자주 하는 실수 (Common Mistakes)

> PCQ 실기시험에서 감점 또는 실격으로 이어지는 자주 하는 실수를 정리합니다.

## 감점/실격 요인 분류

| 분류 | 위험도 | 설명 |
| --- | --- | --- |
| 🔴 실격 | 즉시 불합격 | 안전사고, 장비 손상, 규정 위반 |
| 🟠 중감점 | 10~30점 감점 | 배선 오류, 프로그램 미동작 |
| 🟡 경감점 | 5~10점 감점 | 주석 누락, 코드 가독성 부족 |

---

## 🔴 실격급 실수

### 1. 전원 오배선

| 실수 | 원인 | 예방 |
| --- | --- | --- |
| AC 모델에 DC 전원 연결 | 전원 모델 확인 누락 | 배선 전 PLC 모델명 확인 (DR32H vs DR32H/DC) |
| DC 모델에 AC 전원 연결 | 위와 동일 | 위와 동일 |
| 전원 극성 반대 (DC 모델) | +/- 단자 혼동 | 배선 전 단자 표시 확인 |
| 출력에 정격 초과 부하 | 부하 전류 미확인 | 정격: 릴레이 2A, 트랜지스터 0.5A |

### 2. 장비 손상

| 실수 | 원인 | 예방 |
| --- | --- | --- |
| 출력 단자 쇼트 | COM과 출력 직접 연결 | 배선 후 다용도계로 도통 확인 |
| 릴레이 출력에 과전류 | 정격 초과 부하 연결 | 부하 전류 사전 확인 |
| 통신 포트 손상 | RS-485 배선 오류 | 통신 배선 전 핀 배치도 확인 |

### 3. 시간 초과 (타임아웃)

| 실수 | 원인 | 예방 |
| --- | --- | --- |
| 5시간 내 미완료 | 시간 관리 실패 | 과제별 시간 배분 (1.5시간/과제) |
| 디버깅 시간 과다 | 시뮬레이터 미활용 | 시뮬레이터로 사전 검증 |

## 🟠 중감점 실수

### 1. COM 단자 소스/싱크 오배선

```
❌ 잘못: COM을 0V에 연결하면서 입력에 0V 인가 (동작 안 함)
✅ 정상: COM을 0V에 연결 + 입력에 +24V 인가 (소스 타입)
```

- **결과**: 입력이 정상 동작하지 않아 프로그램 테스트 불가
- **예방**: I/O List의 소스/싱크 타입 확인 후 배선

### 2. 출력 COM 그룹 혼동

```
❌ 잘못: P0020~P0027은 COM0, P0030~P0037은 COM1인데 하나로 연결
✅ 정상: COM 그룹별로 분리 배선
```

- **결과**: 일부 출력 정상, 일부 출력 미동작
- **예방**: PLC 단자 배치도에서 COM 그룹 확인

### 3. 타이머 설정값 오류

| 실수 | 원인 | 예방 |
| --- | --- | --- |
| 3초 설정 시 K3 입력 | 단위(100ms) 미확인 | K30 (30 × 100ms = 3초) |
| 10ms 타이머 사용 | 기본 100ms 타이머와 혼동 | 기본 타이머 사용 시 100ms 단위 |
| 같은 타이머 중복 사용 | T0를 여러 회로에서 사용 | 타이머 번호 중복 확인 |

### 4. 자기유지 회로 오류

```
❌ 잘못: 자기유지 접점 없이 시작 버튼만 연결
         → 버튼에서 손을 떼면 출력 OFF

❌ 잘못: 정지 버튼을 A접점으로 연결
         → 정지 버튼이 평상시 OFF → 회로가 항상 차단

✅ 정상: 시작(A접점) + 자기유지(출력 A접점) 병렬 + 정지(B접점) 직렬
```

### 5. 인터록 누락

```
❌ 잘못: 정역 회전 출력에 인터록 없음
         → 양쪽 동시 ON 시 모터 파손 위험

✅ 정상: 정회전 출력의 B접점을 역회전 회로에, 역회전 출력의 B접점을 정회전 회로에 직렬 연결
```

## 🟡 경감점 실수

### 1. 주석 누락

PCQ 시험에서는 프로그램에 주석(Comment)을 달아 가독성을 높이는 것이 평가 항목입니다.

```
❌ 잘못: 주석 없음
P0000 ──| |──( )── P0020

✅ 정상: 라인 주석 + 디바이스 주석
// [램프1 자기유지 회로]
// P0000: 시작 버튼
// P0020: 램프1 출력
P0000 ──| |──( )── P0020
```

### 2. 디바이스 변수명 미설정

XG5000에서는 디바이스에 변수명(Variable Name)을 설정할 수 있습니다.

```
❌ 잘못: 변수명 없음 (P0000 그대로 사용)

✅ 정상: 변수명 설정
// P0000 → START_BTN (시작 버튼)
// P0020 → LAMP1 (램프1)
```

### 3. 불필요한 라인

```
❌ 잘못: 동일한 동작을 여러 라인으로 분산

✅ 정상: 간결하게 하나의 라인으로 통합
```

### 4. 타임차트와 불일치

- 문제의 타임차트와 프로그램 동작이 미세하게 다른 경우
- 시뮬레이터로 검증하지 않은 경우
- **예방**: 시뮬레이터로 타임차트와 정확히 일치하는지 확인

## 실수 예방 체크리스트 (시험 당일)

### 배선 전 (10분)

- [ ] PLC 모델명 확인 (AC/DC, 릴레이/트랜지스터)
- [ ] I/O List와 디바이스 매칭
- [ ] COM 타입 (소스/싱크) 확인
- [ ] 출력 COM 그룹 확인

### 배선 중 (30분)

- [ ] 전원 배선 (L, N, G) 우선
- [ ] 입력 배선 (P0000~)
- [ ] 출력 배선 (P0020~, COM)
- [ ] 통신 배선 (3과제: RS-485)

### 배선 후 (10분)

- [ ] 단자대 조임 재확인
- [ ] 회로도와 실제 배선 대조
- [ ] 다용도계로 도통/쇼트 확인

### 프로그래밍 (2시간)

- [ ] 래더 작성 (주석 포함)
- [ ] 변수명 설정
- [ ] 시뮬레이터로 동작 검증
- [ ] 타임차트와 비교

### 최종 확인 (10분)

- [ ] 모든 과제 다운로드 완료
- [ ] 실물 테스트 (가능한 경우)
- [ ] 감점 요인 최종 점검
- [ ] 시간 확인 (5시간 내)
