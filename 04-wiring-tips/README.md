## 핵심 체크리스트

- [ ] COM 단자 소스/싱크 배선 확인
- [ ] NPN/PNP 타입 센서/출력기기 매칭
- [ ] 접지선 3종 접지 (100Ω 이하, 2㎟ 이상)
- [ ] PLC 전원부와 입출력부 전원 분리
- [ ] 단자대 조임 토크 규정 준수
- [ ] 배선 후 회로도와 단자배치 대조 확인
- [ ] 타이머 설정값과 타임차트 교차 검증
