## 공개과제 유형 (A~E형)

PCQ 3급 시험은 공개문제 A형 ~ E형을 바탕으로 변형 문제가 출제됩니다.

- **A형 ~ E형**: 기본 공개과제 원형
- **변형 문제**: 기본 유형의 디바이스, 타이머 설정값, 동작 순서 등을 변경한 문제
- 실제 검정에서는 기본 유형뿐만 아니라 변형 유형도 출제되므로 원형과 변형 패턴을 모두 학습해야 합니다.

## 학습 순서 추천

1. **공개문제 모음 (A~E형)** 먼저 학습 — 기본 유형 파악
2. **최신 출제문제** (2026년) — 최신 출제 경향 확인
3. **과거 출제문제** (2024~2025년) — 반복 학습
4. [`level3/self-hold-circuit/`](level3/self-hold-circuit/) → 자기유지 회로 풀이
5. [`level3/timer-application/`](level3/timer-application/) → 타이머 활용 풀이

## 타임차트 해석 방법

PCQ 시험에서는 타임차트를 보고 래더 프로그램을 작성하는 문제가 출제됩니다.

### 해석 순서

1. **입력 신호 타이밍 파악**: 각 입력이 ON/OFF 되는 시점 확인
2. **출력 신호 타이밍 파악**: 각 출력이 ON/OFF 되는 시점 확인
3. **지연 시간 계산**: 입력 ON과 출력 ON 사이의 시간 차이 측정
4. **타이머 설정값 변환**: 측정된 시간을 K값으로 변환 (100ms 단위)
5. **래더 작성**: 타이머 + 접점 조합으로 회로 구성
6. **검증**: 시뮬레이터로 타임차트와 일치하는지 확인
