# 2급 공개문제 풀이

PCQ 2급 시험은 HMI 프로그램 작성, 아날로그 입출력 제어, PLC 분석 등을 평가합니다.

## 과제 구성

| 과제 | 내용 | 주요 명령어 |
| --- | --- | --- |
| 1과제 | HMI 작화 + PLC 프로그래밍 | XP-Builder, 데이터 통신 |
| 2과제 | 아날로그 입출력 제어 | A/D, D/A 변환, PID |
| 3과제 | 고속카운터 / 온도 제어 | 모듈 구성, 통신 |

## 수행 준거 (2급)

1. PLC 메모리 맵을 작성할 수 있다
2. 터치스크린 화면 구성 설계를 할 수 있다
3. 수동운전과 자동운전의 구동동작을 구성할 수 있다
4. 다른 개발자의 프로그램 동작상태 분석을 가능하다
5. 터치스크린 작화 프로그램 사용 및 PLC와의 통신 연결
6. 아날로그 입출력 모듈 구성
7. 고속카운터 모듈 구성 및 활용
8. 온도 입력 및 제어 모듈 구성 및 활용

## 공개문제

2급 통합과제 공개문제 모음 (A~F형)이 2026년 8월에 등록되었습니다.
