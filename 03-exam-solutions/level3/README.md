# 3급 공개문제 풀이

PCQ 3급 시험은 시퀀스 논리회로 분석, 프로그램 로직제어(PLC) 분석, 입출력장치 운영 및 인버터 구동을 평가합니다.

## 과제 구성

시험은 3개 과제로 구성되며, 약 5시간 동안 진행됩니다.

| 과제 | 내용 | 주요 명령어 |
| --- | --- | --- |
| 1과제 | PLC 프로그래밍 (기본 회로) | 자기유지, 타이머, 카운터 |
| 2과제 | PLC 프로그래밍 (응용 회로) | 타이머 + 카운터 조합, 비교 명령어 |
| 3과제 | 인버터 운용 | RS-485 통신, 파라미터 설정 |

## 수행 준거 (3급)

1. 시퀀스도를 보고 공정의 동작사항을 설명할 수 있다
2. 시퀀스도에서 사용되는 기구의 핀번호를 적용하여 시퀀스도를 해석할 수 있다
3. 시퀀스도와 기구배치도를 보고 올바른 배선작업을 할 수 있다
4. 주어진 I/O List를 보고 PLC 접점을 정확하게 연결할 수 있다
5. 공정의 동작사항과 타임차트에 맞도록 PLC 프로그래밍을 수행할 수 있다
6. 작성한 PLC 래더도가 정상적으로 동작되는지 확인할 수 있다
7. 동작사항을 수행할 수 있도록 인버터 파라미터를 정확하게 설정할 수 있다
8. 인버터와 PLC 간 RS-485 통신환경과 조건을 구성할 수 있다
