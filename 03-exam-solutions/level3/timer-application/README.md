# 타이머 활용 예제 (Timer Application)

> PCQ 3급 시험에서 가장 높은 빈도로 출제되는 타이머 응용 회로입니다.
> XG5000 기준으로 작성되었습니다.

## 문제 설명

### 요구사항

시작 버튼(P0000)을 누르면 다음 순서로 램프가 순차 동작한다.

1. P0020 (램프1) ON → 3초 후 OFF
2. P0021 (램프2) ON → 2초 후 OFF
3. P0022 (램프3) ON → 5초 후 OFF → 전체 종료

정지 버튼(P0001)을 누르면 모든 램프 OFF 및 타이머 리셋.

### I/O 할당

| 디바이스 | 용도 | 접점 타입 |
| --- | --- | --- |
| P0000 | 시작 버튼 | A접점 |
| P0001 | 정지 버튼 | B접점 |
| P0020 | 램프1 | 코일 출력 |
| P0021 | 램프2 | 코일 출력 |
| P0022 | 램프3 | 코일 출력 |

## 타임차트

```
P0000 (시작)
       ──┐ ┌───────────────────────────────────────────
         │ │
         └─┘

P0020 (램프1)
       ──┐       ┌──────────────────────────────────────
         │ 3초   │
         └───────┘

P0021 (램프2)       ──┐     ┌────────────────────────────
                        │ 2초 │
                        └─────┘

P0022 (램프3)             ──┐         ┌────────────────
                              │ 5초     │
                              └──────────┘

         |  3초  | 2초 |   5초   |
```

## 래더 프로그램

### 상세 주석 달기

```
// ┌────────────────────────────────────────────────────────────┐
// │ 타이머 순차 동작 회로                                        │
// │                                                             │
// │ 동작 순서:                                                   │
// │   시작 → 램프1(3초) → 램프2(2초) → 램프3(5초) → 종료        │
// │                                                             │
// │ 타이머 할당:                                                  │
// │   T0: 램프1 지속 시간 (3초 = K30)                           │
// │   T1: 램프2 지속 시간 (2초 = K20)                           │
// │   T2: 램프3 지속 시간 (5초 = K50)                           │
// └────────────────────────────────────────────────────────────┘

// [라인 1] 시작 자기유지
P0000 ──| |──┐                    // 시작 버튼
M0000 ──| |──┘                    // 내부 릴레이 자기유지
              │
P0001 ──|/|──┘                    // 정지 버튼 (B접점)
              │
         ( )── M0000              // 실행 플래그

// [라인 2] 램프1 ON + 타이머 T0 시작
M0000 ──| |──|/|──( )── P0020     // M0000 ON, T0 미완료 → 램프1 ON
         T0

M0000 ──| |──[ TON T0 K30 ]──     // 3초 타이머 시작 (30 × 100ms)

// [라인 3] 램프2 ON + 타이머 T1 시작
T0 ──| |──|/|──( )── P0021         // T0 완료 후, T1 미완료 → 램프2 ON
       T1

T0 ──| |──[ TON T1 K20 ]──         // 2초 타이머 시작

// [라인 4] 램프3 ON + 타이머 T2 시작
T1 ──| |──|/|──( )── P0022         // T1 완료 후, T2 미완료 → 램프3 ON
       T2

T1 ──| |──[ TON T2 K50 ]──         // 5초 타이머 시작

// [라인 5] 종료 처리
T2 ──| |──[ RST M0000 ]──          // T2 완료 시 자기유지 해제 → 전체 정지

// [라인 6] 정지 시 전체 리셋
P0001 ──| |──[ RST T0 ]──           // 타이머 리셋
P0001 ──| |──[ RST T1 ]──
P0001 ──| |──[ RST T2 ]──
P0001 ──| |──[ RST M0000 ]──        // 실행 플래그 리셋
```

### 핵심 로직 설명

1. **자기유지 (M0000)**: 시작 버튼 누름 후 정지 또는 종료 조건까지 유지
2. **순차 타이머**: T0 완료 → T1 시작 → T1 완료 → T2 시작 (체인 구조)
3. **출력 제어**: 각 램프는 이전 타이머 완료 접점 + 현재 타이머 미완료 접점으로 ON
4. **정지 처리**: 정지 버튼 누르면 모든 타이머와 자기유지 즉시 리셋

## 시뮬레이터 테스트 절차

1. XG5000 프로젝트 생성 (CPU: XBC-DN32H)
2. 래더 프로그램 입력
3. 시뮬레이터 시작
4. `Ctrl + Enter`로 P0000 강제 ON
5. P0020 ON 확인 후 3초 대기 → P0020 OFF, P0021 ON 확인
6. 2초 대기 → P0021 OFF, P0022 ON 확인
7. 5초 대기 → P0022 OFF, M0000 OFF 확인 (자동 종료)
8. 다시 P0000 ON → 재동작 확인
9. 동작 중 P0001 강제 ON → 모든 출력 OFF, 타이머 리셋 확인

## 변형 문제 대비

### 변형 1: 반복 동작

```
// T2 완료 시 리셋 후 다시 시작 (무한 반복)
T2 ──| |──[ RST T0 ]──              // T0 리셋
T2 ──| |──[ RST T1 ]──              // T1 리셋
T2 ──| |──[ RST T2 ]──              // T2 리셋
// M0000은 유지 → 자동으로 다시 시작
```

### 변형 2: 카운터로 반복 횟수 제한

```
// 3회 반복 후 자동 정지
T2 ──| |──[ CTU C0 K3 ]──           // 완료 시 카운트업
C0 ──| |──[ RST M0000 ]──           // 3회 도달 시 정지
T2 ──| |──[ RST T0 ]──              // 타이머 리셋 (반복)
T2 ──| |──[ RST T1 ]──
T2 ──| |──[ RST T2 ]──

// 시작 시 카운터 리셋
P0000 ──↑──[ RST C0 ]──             // 시작 버튼 상승 에지에서 카운터 리셋
```

### 변형 3: 깜빡임 추가

```
// 램프1이 3초 동안 0.5초 간격으로 깜빡임
M0000 ──| |──|/|──[ TON T10 K5 ]──  // 0.5초 펄스 타이머
         T0

T10 ──| |──[ RST T10 ]──            // 자체 리셋 (반복)

T10 ──| |──( )── P0020              // 깜빡임 출력
// T0가 완료되면 정지
```
