# 자기유지 회로 예제 (Self-Holding Circuit)

> PCQ 3급 시험의 가장 기본이 되는 회로입니다.
> XG5000 기준으로 작성되었습니다.

## 문제 설명

### 요구사항

- 시작 버튼(P0000)을 누르면 램프(P0020)가 ON 되고, 버튼에서 손을 떼어도 유지
- 정지 버튼(P0001)을 누르면 램프(P0020)가 OFF

### I/O 할당

| 디바이스 | 용도 | 접점 타입 |
| --- | --- | --- |
| P0000 | 시작 버튼 | A접점 |
| P0001 | 정지 버튼 | B접점 |
| P0020 | 출력 (램프/모터) | 코일 |

## 타임차트

```
P0000 (시작)
         ──┐   ┌──────────────────────────────
           │   │
           └───┘

P0001 (정지)
──────────────────────────────────┐
                                 │
                                 └──

P0020 (출력)
         ──┐                    ┐
           │                    │
           └────────────────────┘
         ↑P0000 ON           ↑P0001 ON
         (유지)              (해제)
```

## 래더 프로그램

### XG5000 래더 코드

```
// ┌─────────────────────────────────────────────────────────┐
// │ 자기유지 회로 (Self-Holding Circuit)                    │
// │                                                        │
// │ P0000: 시작 버튼 (A접점, 평상시 열림)                   │
// │ P0001: 정지 버튼 (B접점, 평상시 닫힘)                   │
// │ P0020: 출력 코일 (램프/모터)                            │
// │                                                        │
// │ 동작:                                                   │
// │   1. P0000 ON → P0020 ON                               │
// │   2. P0020 자기유지 (P0000 OFF 후에도 유지)             │
// │   3. P0001 ON (B접점 차단) → P0020 OFF → 자기유지 해제  │
// └─────────────────────────────────────────────────────────┘

// 래더 도면:
//
//   P0000    P0020       P0001        P0020
//   ──| |──┬──| |──────────|/|────────( )──
//         │
//         │
//         └── (P0020 자기유지 접점, 병렬 연결)
//

```

### 의사 코드 (Pseudo Code)

```
// 래더 라인 1: 자기유지 회로
// P0000 (시작)와 P0020 (자기유지)의 OR → P0001 (정지 B접점) AND → P0020 출력

// XG5000 입력 순서:
// 1. F3 → P0000 입력 (A접점)
// 2. F5 → 세로선 (병렬 분기)
// 3. F3 → P0020 입력 (A접점, 자기유지)
// 4. F9 → P0001 입력 (B접점, 정지) - F4로 B접점 선택
// 5. F9 → P0020 출력 (코일)
```

## 상세 주석

```
[라인 1]
P0000 ──| |──┐                   // 시작 버튼 (A접점)
              │
P0020 ──| |──┘                   // 자기유지: P0020 출력이 ON 되면
              │                   //           자기 접점으로 전류 유지
              │
P0001 ──|/|──┘                   // 정지 버튼 (B접점): 평상시 닫힘
                                  // P0001이 ON 되면 회로 차단 → P0020 OFF
              │
         ( )── P0020              // 출력 코일: 램프/모터 구동
```

## 시뮬레이터 테스트 절차

1. XG5000에서 프로젝트 생성 (CPU: XBC-DN32H)
2. 위 래더 프로그램 입력
3. 시뮬레이터 시작 (도구 모음 → 시뮬레이터 시작)
4. `Ctrl + Enter`로 P0000 강제 ON → P0020 ON 확인
5. P0000 강제 OFF → P0020 유지 확인 (자기유지 정상)
6. `Ctrl + Enter`로 P0001 강제 ON → P0020 OFF 확인 (정상 정지)
7. P0001 강제 OFF 후 P0000 다시 ON → 재동작 확인

## 변형 문제 대비

PCQ 실제 시험에서는 자기유지 회로를 다음과 같이 변형하여 출제합니다.

### 변형 1: 타이머 추가

```
// 시작 후 5초 지연 출력
P0000 ──| |──┐
P0020 ──| |──┘  (자기유지)
              │
P0001 ──|/|──┘
              │
         [ TON T0 K50 ]          // 5초 타이머
              │
T0 ──| |──( )── P0020           // 5초 후 P0020 ON
```

### 변형 2: 다중 출력

```
// 시작 시 램프 + 부저 동시 동작
P0000 ──| |──┐
P0020 ──| |──┘  (자기유지)
              │
P0001 ──|/|──┘
              ├──( )── P0020     // 램프
              └──( )── P0021     // 부저
```

### 변형 3: 인터록 추가

```
// 안전 센서(P0002)가 ON일 때만 동작
P0000 ──| |──┐
P0020 ──| |──┘  (자기유지)
              │
P0002 ──| |──┘  (안전 센서)
              │
P0001 ──|/|──┘  (정지)
              │
         ( )── P0020
```
