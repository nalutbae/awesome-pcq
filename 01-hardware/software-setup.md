# 개발 소프트웨어 설치 가이드

> XG5000 (PLC 프로그래밍) 및 XP-Builder (HMI 작화) 설치 가이드

## XG5000

### 개요

XG5000은 LS일렉트릭 XGT/XGB 시리즈 PLC를 위한 통합 프로그래밍 소프트웨어입니다. 프로그램 작성, 디버깅, 모니터링, 인쇄 기능을 제공합니다.

### 다운로드

| 버전 | 링크 | 비고 |
| --- | --- | --- |
| XG5000 V4.81.1 (베타) | [솔루션스퀘어](https://sol.ls-electric.com/kr/ko/product/document/25892) | 2026.01.16 업데이트 |
| XG5000 정식 버전 | [솔루션스퀘어](https://sol.ls-electric.com/kr/ko/product/document/25892) | 별도 제공 |
| XG5000 사용설명서 V3.0 | [PCQ 자료실](https://pcq.co.kr/) | PCQ 홈페이지 회원가입 후 다운로드 |

> **시스템 요구사항**: XG5000 V4.71 이상 필요 (XBC-H 타입 기준)

### 설치 순서

1. 솔루션스퀘어에서 XG5000 설치 파일 다운로드
2. 압축 해제 후 `Setup.exe` 실행
3. 설치 마법사 안내에 따라 설치 진행
4. 설치 완료 후 바탕화면의 XG5000 아이콘으로 실행
5. [프로젝트] → [새 프로젝트] 클릭
6. 시리즈 선택: **XGB** (일체형)
7. CPU 종류 선택: **XBC-DN32H** 또는 **XBC-DR32H**
8. 프로젝트 생성 후 래더 작성 시작

### 핵심 단축키

| 단축키 | 기능 |
| --- | --- |
| F3 | A접점 (평상시 열림, Normally Open) |
| F4 | B접점 (평상시 닫힘, Normally Closed) |
| F9 | 코일 출력 |
| F10 | 응용 명령어 (MOV, ADD 등) |
| F5 | 세로선 (병렬 접속) |
| F6 | 가로선 삭제 |
| Ctrl + Enter | 접점 강제 ON/OFF (시뮬레이터 모드) |
| F2 | 래더 라인 삽입 |
| Shift + F2 | 래더 라인 삭제 |

### 시뮬레이터 사용법

실물 PLC 없이 프로그램을 테스트할 수 있는 기능입니다.

1. 도구 모음에서 [시뮬레이터 시작] 아이콘 클릭
2. 하단 출력 창에 에러가 없는지 확인
3. 프로그램이 파란색 선으로 활성화되면 `Ctrl + Enter`로 접점 강제 ON/OFF
4. 타이머, 카운터 동작 상태를 실시간으로 확인

## XP-Builder

### 개요

XP-Builder는 LS일렉트릭 HMI(터치스크린) 작화 소프트웨어입니다. PCQ 2급 이상에서 HMI 작화가 필수 과제입니다.

### 다운로드

| 버전 | 링크 | 비고 |
| --- | --- | --- |
| XP-Builder 최신 (3.xx) | [솔루션스퀘어](https://sol.ls-electric.com/kr/ko/product/document/2204) | iXP2, eXP2 등 최신 시리즈 |
| XP-Builder V2.20 | [솔루션스퀘어](https://sol.ls-electric.com/kr/ko/product/document/2204) | XP 시리즈 (단종) 사용자용 |
| XP-Builder 사용설명서 | [솔루션스퀘어](https://sol.ls-electric.com/kr/ko/product/document/1685) | 한국어 매뉴얼 |

### 적용 제품

| 시리즈 | 상태 | 비고 |
| --- | --- | --- |
| iXP2 | 판매중 | WindowsCE 기반 |
| eXP2 | 판매중 | WindowsCE 기반 |
| iXP2H | 판매중 | Handy형 |
| IPC/wXP | 판매중 | PC 기반 |
| iXP | 단종 | — |
| eXP | 단종 | — |
| XP | 단종 | V2.20 사용 |

### PCQ 시험과의 관계

- **3급**: HMI 작화 없음 (PLC 프로그래밍 + 인버터 운용 중심)
- **2급**: HMI 프로그램 작성 필수 (터치스크린 작화 + PLC 통신)
- **1급**: HMI + 시스템 시운전 및 분석

### 핵심 작화 기능

| 기능 | 설명 |
| --- | --- |
| 화면 구성 | 베이스 화면, 팝업 화면, 겹침 화면 |
| 오브젝트 | 램프, 스위치, 숫자 입력기, 문자 표시기, 그래프 |
| 통신 설정 | PLC 연결: XBC 시리즈, 프로토콜: XGT 전용 프로토콜 |
| 디바이스 맵 | PLC 디바이스(P, M, T, C, D 등)와 HMI 오브젝트 연결 |
| 레시피 | 제품별 파라미터 관리 기능 |
| 알람 | 이력 알람, 흐름 알람, 블록 알람 |

### 설치 순서

1. 솔루션스퀘어에서 XP-Builder 설치 파일 다운로드
2. 압축 해제 후 설치 파일 실행
3. 설치 마법사 안내에 따라 설치
4. 실행 후 [새 프로젝트] 생성
5. HMI 기종 선택 (예: iXP2)
6. 통신 설정: PLC 기종 XBC-DN32H, 프로토콜 XGT
7. 화면 작화 시작
