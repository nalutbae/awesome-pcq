# XGB 시리즈 PLC 사양 (H타입)

> PCQ 시험에 사용되는 LS일렉트릭 XGB 시리즈 CPU 모듈의 상세 사양입니다.
> 출처: [XGB 기본유닛 설치가이드](https://ssq.ls-electric.com/uploads/document/17699898942730/XBC-H_XBM-S_Manual_V2.6_202601_KR.pdf)

## 모델별 사양 요약

| 모델명 | 전원 | 입력 | 출력 | 고속카운터 | 위치결정 |
| --- | --- | --- | --- | --- | --- |
| **XBC-DR32H** | AC 100~240V | DC24V 16점 | 릴레이 16점 | 8점 | 미지원 |
| **XBC-DN32H** | AC 100~240V | DC24V 16점 | 트랜지스터 16점 | 8점 | 2축 (APM) |
| **XBC-DR64H** | AC 100~240V | DC24V 32점 | 릴레이 32점 | 8점 | 미지원 |
| **XBC-DN64H** | AC 100~240V | DC24V 32점 | 트랜지스터 32점 | 8점 | 2축 (APM) |
| XBC-DR32H/DC | DC 24V | DC24V 16점 | 릴레이 16점 | 8점 | 미지원 |
| XBC-DN32H/DC | DC 24V | DC24V 16점 | 트랜지스터 16점 | 8점 | 2축 (APM) |
| XBC-DR64H/DC | DC 24V | DC24V 32점 | 릴레이 32점 | 8점 | 미지원 |
| XBC-DN64H/DC | DC 24V | DC24V 32점 | 트랜지스터 32점 | 8점 | 2축 (APM) |

> **시험 주요 모델**: XBC-DR32H (릴레이 출력형) 및 XBC-DN32H (트랜지스터 출력형)

## 공통 성능 규격

| 항목 | 규격 |
| --- | --- |
| 연산 방식 | 반복연산, 정주기 연산, 인터럽트 연산, 고정주기 운전 |
| 입출력 제어 방식 | 스캔동기 일괄처리 방식 (리프레시 방식) + 명령어에 의한 다이렉트 방식 |
| 연산 처리 속도 | 기본명령: **60ns/step** |
| 프로그램 메모리 용량 | XBC: **15Kstep** / XEC: 250KB |
| 최대 증설 단수 | 기본 + 증설 10단 |
| 운전 모드 | RUN, STOP, DEBUG |
| 자기진단 | 연산지연감시, 메모리 이상, 입출력 이상 |
| 프로그램 접속 포트 | USB(1Ch), RS-232C(1Ch) |
| 정전 시 데이터 보존 | 기본 파라미터에서 래치(리테인) 영역 설정 |
| 내장 통신 | Cnet (RS-232C, RS-485) |
| 내장 기능 | PID, 고속카운터, RTC |

## 입력 사양 (XBC-DR32H / XBC-DN32H)

| 항목 | 규격 |
| --- | --- |
| 입력 점수 | 16점 |
| 입력 전압 | DC24V |
| 입력 타입 | 소스/싱크 타입 (공통단 배선에 의해 선택) |
| 입력 응답 시간 | 일반: 10ms 이하 / 고속: 0.1ms 이하 |

## 출력 사양

### 릴레이 출력 (XBC-DR32H)

| 항목 | 규격 |
| --- | --- |
| 출력 점수 | 16점 |
| 출력 타입 | 릴레이 (a접점) |
| 정격 부하 | DC24V 2A / AC220V 2A |
| 기계적 수명 | 1,000만 회 이상 |
| 전기적 수명 | 30만 회 이상 (정격 부하) |

### 트랜지스터 출력 (XBC-DN32H)

| 항목 | 규격 |
| --- | --- |
| 출력 점수 | 16점 |
| 출력 타입 | 트랜지스터 (싱크 타입) |
| 정격 부하 | DC24V 0.5A |
| 응답 시간 | OFF→ON: 0.2ms 이하 / ON→OFF: 0.2ms 이하 |
| 고속 펄스 출력 | 100kHz (APM 사용 시) |

## 설치 환경

| 항목 | 규격 |
| --- | --- |
| 주위 온도 | 0 ~ 55℃ |
| 보관 온도 | -25 ~ 70℃ |
| 주위 습도 | 5 ~ 95%RH (결로 없음) |
| 내진동 | 10 ~ 57Hz, 진폭 0.075mm / 57 ~ 150Hz, 1G |
| 항목 규격 | IEC 61131-2 준수 |

## 배선 시 주의사항

1. 정격 전압 확인 후 배선 (AC 100~240V 모델 vs DC 24V 모델)
2. 단자대 조임 토크 규정 준수
3. 주변에 인화성 물질 배치 금지
4. 직접 진동 환경 피하기
5. PLC 전원부와 입출력부 전원 계통 분리
6. 접지: 3종 접지 (접지저항 100Ω 이하), 접지선 2㎟ 이상
