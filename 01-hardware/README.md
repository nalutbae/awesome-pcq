# 개발 환경 및 하드웨어

이 디렉토리는 PCQ 시험에 사용되는 PLC 하드웨어 사양과 개발 소프트웨어 설치 가이드를 제공합니다.

## 핵심 요약

- **PLC 시리즈**: LS일렉트릭 XGB (H타입)
- **주요 모델**: XBC-DR32H (릴레이 출력), XBC-DN32H (트랜지스터 출력)
- **프로그래밍 소프트웨어**: XG5000 (V4.71 이상)
- **HMI 작화 소프트웨어**: XP-Builder
- **다운로드 케이블**: USB-301A (USB), PMC-310S (RS-232C)
