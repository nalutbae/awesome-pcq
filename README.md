## 소개

**PCQ(PLC Control Qualification, PLC제어기술자)** 는 산업통상자원부에 등록된 민간자격(등록번호 2016-003575)으로, LS일렉트릭과 다산에듀가 공동으로 개발하고 운영하는 자격증입니다. PLC를 기반으로 산업현장에서 사용되는 자동화 공정에 맞춰 프로그램을 작성하고 기기를 운용할 수 있는 능력을 평가합니다.

### 자격 등급

| 등급 | 수준 | 주요 직무 |
| --- | --- | --- |
| **1급** | 세계 올림픽 수준 | 시스템 설계, 서보시스템 운영, 제어 시스템 통신망 구성 |
| **2급** | 전국기능경기대회 수준 | HMI 프로그램 작성, 아날로그 입출력 제어, PLC 분석 |
| **3급** | 지방기능경기대회 수준 | 시퀀스 논리회로 분석, PLC 분석, 인버터 운용 |

### 시험 개요

| 평가유형 | 부여 과제 수 | 소요시간 | 합격기준 |
| --- | --- | --- | --- |
| 실기시험 | 3개 과제 | 약 5시간 | 70점 이상 (100점 만점) |

- **응시자격**: 3급은 제한 없음 / 2급은 3급 취득자 / 1급은 2급 취득자
- **시험응시료**: 3급 130,000원
- **자격 유효기간**: 취득 후 3년 (보수교육으로 갱신 가능)

### 왜 이 저장소가 필요한가?

PCQ 시험은 국내 자격증(LS일렉트릭 기기 중심) 특성상 글로벌 GitHub 생태계에서 자료를 찾기 매우 어렵습니다. 수험생들은 매번 유튜브나 개별 블로그를 파편적으로 찾아다녀야 하는 불편함이 있습니다. 이 저장소는 그 간극을 메웁니다.

## 1. ⚙️ 개발 환경 및 하드웨어

> 📂 **상세 문서**: [`01-hardware/`](01-hardware/)

PCQ 시험에서 사용되는 LS일렉트릭 XGB 시리즈 PLC의 사양과 개발 소프트웨어(XG5000, XP-Builder) 설치 가이드를 제공합니다.

### 핵심 하드웨어

| 모델명 | 전원 | 입력 | 출력 | 특징 |
| --- | --- | --- | --- | --- |
| **XBC-DR32H** | AC 100~240V | DC24V 16점 | 릴레이 16점 | 시험용 기본 모델 |
| **XBC-DN32H** | AC 100~240V | DC24V 16점 | 트랜지스터 16점 | 고속 출력, APM 지원 |
| **XBC-DR64H** | AC 100~240V | DC24V 32점 | 릴레이 32점 | 확장형 |
| **XBC-DN64H** | AC 100~240V | DC24V 32점 | 트랜지스터 32점 | 확장형, APM 지원 |

### 주요 사양

- **연산 처리 속도**: 기본 명령 60ns/step
- **프로그램 메모리**: XBC 15Kstep
- **최대 증설**: 기본 + 증설 10단
- **내장 기능**: Cnet(RS-232C/RS-485), PID, 고속카운터, RTC
- **프로그램 접속 포트**: USB(1Ch), RS-232C(1Ch)

### 개발 소프트웨어

| 소프트웨어 | 용도 | 다운로드 |
| --- | --- | --- |
| **XG5000** | PLC 프로그래밍, 디버깅, 모니터링 | [솔루션스퀘어](https://sol.ls-electric.com/kr/ko/product/document/25892) |
| **XP-Builder** | HMI 터치스크린 작화 | [솔루션스퀘어](https://sol.ls-electric.com/kr/ko/product/document/2204) |

## 2. 📘 핵심 이론 및 문법

> 📂 **상세 문서**: [`02-core-concepts/`](02-core-concepts/)

### 기본 회로

- **A접점 (Normaly Open)**: 평상시 열려있는 접점 (F3 단축키)
- **B접점 (Normally Closed)**: 평상시 닫혀있는 접점 (F4 단축키)
- **자기유지 회로**: 출력 코일을 통해 자체를 유지하는 회로
- **인터록 회로**: 상호 배제를 통한 안전 회로

### 필수 명령어 집합

| 명령어 | 단축키 | 기능 | PCQ 출제 빈도 |
| --- | --- | --- | --- |
| A접점 | F3 | 평상시 열림 접점 | ★★★★★ |
| B접점 | F4 | 평상시 닫힘 접점 | ★★★★★ |
| 코일 출력 | F9 | 출력 코일 | ★★★★★ |
| 응용 명령어 | F10 | MOV, ADD 등 응용 | ★★★★☆ |
| 상승 펄스 | — | 펄스 상승 에지 검출 | ★★★★☆ |
| 하강 펄스 | — | 펄스 하강 에지 검출 | ★★★☆☆ |

### 타이머 / 카운터

- **TON (On-Delay Timer)**: 입력 ON 후 설정 시간 경과 시 출력 ON
- **TOF (Off-Delay Timer)**: 입력 OFF 후 설정 시간 경과 시 출력 OFF
- **CTU (Up Counter)**: 펄스 입력마다 카운트 증가, 설정값 도달 시 출력 ON

### 데이터 처리

- **MOV**: 데이터 이동 명령어
- **비교 명령어**: `=`, `>`, `<`, `>=`, `<=`, `<>`

### 공개과제 유형 (A~E형)

## 4. 🛠 실기 배선 팁

> 📂 **상세 문서**: [`04-wiring-tips/`](04-wiring-tips/)

### 배선 핵심 체크리스트

- **COM 단자 배선**: 입력 공통단(COM)의 소스/싱크 타입 확인
- **NPN/PNP 타입 구분**: 센서 및 출력 기기의 타입 매칭 필수
- **접지**: 3종 접지(접지저항 100Ω 이하), 접지선 2㎟ 이상
- **전원 분리**: PLC 전원부와 입출력부 전원 계통 분리

### 자주 하는 실수 (감점/실격 요인)

| 실수 유형 | 원인 | 예방 방법 |
| --- | --- | --- |
| 단선 | 태포트조임 불량, 진동 | 규정 토크로 조임, 배선 후 재확인 |
| 오배선 | COM 단자 소스/싱크 혼동 | 배선 전 회로도와 단자배치 대조 |
| 타임아웃 | 타이머 설정값 오류 | 타임차트와 프로그램 설정값 교차 검증 |
