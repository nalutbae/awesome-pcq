# 카운터 (Counters)

> PCQ 시험에서 출제되는 카운터 명령어를 정리합니다.

## 카운터 개요

| 항목 | 규격 |
| --- | --- |
| 카운터 개수 | 기본 256점 (C0 ~ C255) |
| 설정 범위 | 0 ~ 65535 |
| 정전 유지 | 기본 파라미터에서 래치 영역 설정 시 유지 |
| 카운트 방식 | 업카운터 (CTU), 다운카운터 (CTD) |

## 1. CTU (Up Counter, 업카운터)

> 펄스 입력마다 카운트 값이 증가하고, 설정값에 도달하면 출력이 ON 되는 카운터입니다.

### 래더 로직

```
// CTU 예제: P0000 펄스 5회 입력 시 P0020 ON
// 카운터 C0, 설정값 K5
P0000 ──| |──[ CTU C0 K5 ]──   // P0000 상승 에지마다 C0 카운트업

C0 ──| |──( )── P0020           // C0가 설정값 도달 시 ON

// 리셋
P0001 ──| |──[ RST C0 ]──      // P0001 ON 시 C0 리셋
```

### 동작 원리

```
P0000 ──┐ ┌──┐ ┌──┐ ┌──┐ ┌──┐ ┌──┐
        │ │  │ │  │ │  │ │  │ │  │
        └─┘  └─┘  └─┘  └─┘  └─┘  └─
        1    2    3    4    5
                            ↑
C0     0 → 1 → 2 → 3 → 4 → 5  (설정값 도달)

P0020                       ──────── ON (유지)
```

### 설정값 계산

카운터는 펄스 개수를 직접 설정합니다. 타이머처럼 단위 변환이 필요 없습니다.

| 목표 | 설정값 |
| --- | --- |
| 3회 카운트 | K3 |
| 5회 카운트 | K5 |
| 10회 카운트 | K10 |
| 100회 카운트 | K100 |

### 시뮬레이터 테스트

1. P0000 강제 ON/OFF 반복 (Ctrl+Enter)
2. C0의 현재값이 1씩 증가하는지 확인
3. C0가 5에 도달하면 C0 접점 ON → P0020 ON 확인
4. P0001 강제 ON → C0 리셋, P0020 OFF 확인

## 2. 카운터 응용 회로

### 2.1 펄스 발생 + 카운터 (반복 동작 N회)

> 타이머로 펄스를 발생시키고 카운터로 반복 횟수를 제어하는 회로
> PCQ 기출문제에서 자주 출제되는 패턴입니다.

```
// 1초 펄스 발생 → 5회 반복 후 정지
// P0000: 시작 버튼
// P0020: 출력 (램프)

// 1초 펄스 발생
P0000 ──| |──[ TON T0 K10 ]──       // 1초 타이머
T0 ──| |──[ RST T0 ]──              // T0 완료 시 자체 리셋 (반복)

// T0 펄스로 카운터 카운트업
T0 ──| |──[ CTU C0 K5 ]──           // T0 상승 에지마다 카운트

// 5회 도달 전까지 출력 ON
P0000 ──| |──|/|──( )── P0020       // C0 미달성 시 P0020 ON
         C0

// 5회 도달 시 전체 리셋
C0 ──| |──[ RST C0 ]──              // C0 리셋 (다시 시작 가능)
```

### 2.2 버튼 누름 횟수 카운트

> 버튼을 누른 횟수에 따라 다른 출력을 제어하는 회로

```
// P0000: 버튼
// P0020: 3회 누름 시 ON
// P0021: 5회 누름 시 ON
// P0001: 리셋

P0000 ──| |──[ CTU C0 K5 ]──        // 최대 5까지 카운트

// 비교 명령어 활용
C0 == K3 ──────( )── P0020          // C0가 3일 때
C0 == K5 ──────( )── P0021          // C0가 5일 때

P0001 ──| |──[ RST C0 ]──           // 리셋
```

## 3. 카운터 리셋 방법

| 방법 | 명령어 | 설명 |
| --- | --- | --- |
| 리셋 버튼 | `[ RST C0 ]` | 특정 조건에서 카운터 값을 0으로 초기화 |
| 자동 리셋 | `C0 ──| |──[ RST C0 ]` | 설정값 도달 시 자동 리셋 (반복 동작) |
| 정지 후 리셋 | 정지 버튼과 리셋 연동 | 시스템 정지 시 모든 카운터 초기화 |

## 4. 타이머 + 카운터 조합 (장시간 타이머)

> 타이머만으로 긴 시간을 설정하기 어려울 때 카운터를 조합합니다.

```
// 1분 타이머 × 60회 = 1시간 타이머
// P0000: 시작
// P0020: 1시간 후 출력

// 1분(60초) 타이머
P0000 ──| |──[ TON T0 K600 ]──     // 60초 (600 × 100ms)

// T0 완료 시 카운터 카운트업 + 타이머 리셋
T0 ──| |──[ CTU C0 K60 ]──          // 60회 카운트
T0 ──| |──[ RST T0 ]──              // T0 리셋 (1분 간격 펄스)

// 60회(1시간) 도달 시 출력
C0 ──| |──( )── P0020               // 1시간 후 ON
```

## 카운터 사용 시 주의사항

| 주의사항 | 설명 |
| --- | --- |
| 상승 에지 | 카운터는 펄스의 **상승 에지**에서만 카운트 (ON 유지 시 1회만) |
| 중복 사용 | 같은 카운터를 여러 회로에서 사용 금지 |
| 리셋 우선 | RST 명령어가 카운트보다 우선 (같은 스캔 내에서) |
| 정전 유지 | 래치 영역 설정 시 정전 후에도 값 유지 (주의!) |
| 초기화 | 프로그램 시작 시 반드시 카운터 초기화 여부 확인 |
