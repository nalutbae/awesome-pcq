# 데이터 처리 (Data Processing)

> PCQ 시험에서 출제되는 데이터 처리 명령어를 정리합니다.

## MOV (데이터 이동)

### 기본 형식

```
[MOV 원본 목적지]    // 원본 데이터를 목적지에 복사
```

### 사용 예

```
// 상수를 데이터 레지스터에 저장
P0000 ──| |──[ MOV K100 D0 ]──      // D0 = 100

// 데이터 레지스터 간 복사
P0001 ──| |──[ MOV D0 D10 ]──       // D10 = D0

// 타이머/카운터 설정값을 변수로 관리
P0002 ──| |──[ MOV K50 D100 ]──     // D100 = 50 (타이머 설정용)
// 이후 T0의 설정값을 D100으로 지정 가능
```

### 활용: 가변 타이머

```
// 스위치 조합에 따라 타이머 설정값 변경
// P0000: 짧은 시간 (3초)
// P0001: 중간 시간 (5초)
// P0002: 긴 시간 (10초)
// T0 설정값: D0 사용

P0000 ──| |──[ MOV K30 D0 ]──       // 3초
P0001 ──| |──[ MOV K50 D0 ]──       // 5초
P0002 ──| |──[ MOV K100 D0 ]──     // 10초

P0010 ──| |──[ TON T0 D0 ]──        // T0 설정값: D0 (가변)
```

## 비교 명령어

### 기본 형식

```
[ D0 == K5 ]    // D0가 5와 같은가?
[ D0 > K5 ]     // D0가 5보다 큰가?
[ D0 < K5 ]     // D0가 5보다 작은가?
[ D0 >= K5 ]    // D0가 5보다 크거나 같은가?
[ D0 <= K5 ]    // D0가 5보다 작거나 같은가?
[ D0 != K5 ]    // D0가 5와 다른가?
```

### 사용 예

```
// 카운터 값에 따른 분기
// C0가 3과 같을 때 P0020 ON
// C0가 5와 같을 때 P0021 ON
// C0가 5보다 크면 P0022 ON

C0 == K3 ──────( )── P0020          // 3회 도달
C0 == K5 ──────( )── P0021          // 5회 도달
C0 > K5  ──────( )── P0022          // 5회 초과
```

### 실용 예제: 카운터 범위 판별

```
// C0가 1~5 사이면 P0020 ON
// C0가 6~10 사이면 P0021 ON
// C0가 10 초과면 P0022 ON

C0 >= K1 ──| |── C0 <= K5 ──( )── P0020    // 1 ≤ C0 ≤ 5
C0 >= K6 ──| |── C0 <= K10 ──( )── P0021   // 6 ≤ C0 ≤ 10
C0 > K10 ──| |──( )── P0022                  // C0 > 10
```

## 비교 명령어 응용: 타임차트 구현

PCQ 시험에서 타임차트를 보고 래더를 작성할 때, 비교 명령어를 활용하면 복잡한 조건을 간단히 구현할 수 있습니다.

```
// 타임차트:
// 0~3초: P0020 ON
// 3~7초: P0021 ON
// 7초~:  P0022 ON

// T0: 경과 시간 타이머 (P0000 시작 후 카운트)
P0000 ──| |──[ TON T0 K9999 ]──    // 최대치까지 카운트 (경과 시간 측정)

// 구간 판별
T0 < K30  ──────( )── P0020         // 0~3초 (T0 < 30)
T0 >= K30 ──| |── T0 < K70 ──( )── P0021  // 3~7초
T0 >= K70 ──────( )── P0022         // 7초~
```

## 사칙연산

### 기본 명령어

```
[ADD D0 D1 D2]    // D2 = D0 + D1 (덧셈)
[SUB D0 D1 D2]    // D2 = D0 - D1 (뺄셈)
[MUL D0 D1 D2]    // D2 = D0 × D1 (곱셈)
[DIV D0 D1 D2]    // D2 = D0 ÷ D1 (나눗셈)
```

### 활용 예

```
// 센서 값 스케일링
// D0: 아날로그 입력 (0~1000)
// D10: 변환된 값 (0~100)
// 계산: D10 = D0 × 100 / 1000 = D0 / 10

P0000 ──| |──[ DIV D0 K10 D10 ]──   // D10 = D0 / 10
```
