# 타이머 (Timers)

> PCQ 시험에서 가장 높은 빈도로 출제되는 타이머 명령어를 정리합니다.

## 타이머 개요

XGB 시리즈 PLC의 타이머는 다음과 같은 특징이 있습니다.

| 항목 | 규격 |
| --- | --- |
| 타이머 개수 | 기본 512점 (T0 ~ T511) |
| 설정 단위 | 100ms (기본), 10ms (고속 타이머) |
| 설정 범위 | 0 ~ 65535 (100ms 기준: 0 ~ 6553.5초) |
| 정전 유지 | 기본 파라미터에서 래치 영역 설정 시 |

## 1. TON (On-Delay Timer, 온 딜레이 타이머)

> 입력이 ON 된 후 설정 시간이 경과하면 출력이 ON 되는 타이머입니다.
> PCQ 시험에서 **가장 빈번하게 출제**됩니다.

### 동작 원리

```
입력 ON ──────┐
              │  설정 시간 (예: 5초)
              ├──────────┐
              │          │
출력         ───────────┘ ON

입력 OFF ──┐
           │
출력      ─┘ 즉시 OFF (리셋)
```

### 래더 로직

```
// TON 예제: P0000이 ON 된 후 5초 뒤 P0020 ON
// 타이머 T0, 설정값 K50 (50 × 100ms = 5초)
P0000 ──| |──[ TON T0 K50 ]──

// 타이머 완료 접점으로 출력
T0 ──| |──( )── P0020
```

### 설정값 계산

| 설정 시간 | K값 (100ms 기준) | 계산 |
| --- | --- | --- |
| 1초 | K10 | 10 × 100ms |
| 2초 | K20 | 20 × 100ms |
| 3초 | K30 | 30 × 100ms |
| 5초 | K50 | 50 × 100ms |
| 10초 | K100 | 100 × 100ms |
| 30초 | K300 | 300 × 100ms |
| 60초 (1분) | K600 | 600 × 100ms |

### 시뮬레이터 테스트

1. P0000 강제 ON
2. T0의 현재값이 0에서 50까지 카운트업 되는지 확인
3. T0가 50에 도달하면 T0 접점이 ON → P0020 ON 확인
4. P0000 강제 OFF → T0 리셋, P0020 OFF 확인

## 2. TOF (Off-Delay Timer, 오프 딜레이 타이머)

> 입력이 OFF 된 후 설정 시간이 경과하면 출력이 OFF 되는 타이머입니다.

### 동작 원리

```
입력 ON ──────┐          OFF
              │
              │
출력      ────┘          ─────┐
                                  │  설정 시간
                                  ├────────┐
                                          │
출력                                     ─┘ OFF
```

### 래더 로직

```
// TOF 예제: P0000이 OFF 된 후 3초 뒤 P0020 OFF
// 타이머 T1, 설정값 K30 (30 × 100ms = 3초)
P0000 ──| |──[ TOF T1 K30 ]──

T1 ──| |──( )── P0020   // T1이 카운트 중이면 P0020 ON 유지
```

### 활용 예

- 모터 정지 후 팬을 일정 시간 더 가동 (냉각 목적)
- 표시등 지연 소등
- 도어 닫힘 후 일정 시간 램프 유지

## 3. 타이머 응용 회로

### 3.1 순차 동작 (Sequential)

> 여러 출력을 순차적으로 ON 하는 회로 (PCQ 기출 유형)

```
// 시작 버튼 P0000 → 3초 후 P0020 → 추가 2초 후 P0021 → 추가 5초 후 P0022
P0000 ──| |──[ TON T0 K30 ]──   // 3초
T0 ──| |──[ TON T1 K20 ]──      // 추가 2초 (T0 ON 후)
T1 ──| |──[ TON T2 K50 ]──      // 추가 5초 (T1 ON 후)

T0 ──| |──( )── P0020            // 3초 후 ON
T1 ──| |──( )── P0021            // 5초 후 ON
T2 ──| |──( )── P0022            // 10초 후 ON
```

### 3.2 깜빡임 회로 (Blink / Flash)

> 일정 주기로 출력을 ON/OFF 하는 회로 (램프 깜빡임)

```
// 1초 간격 깜빡임
P0000 ──| |──[ TON T0 K10 ]──   // 1초 타이머
T0 ──|/|──[ TON T0 K10 ]──      // T0가 ON 되면 자신을 리셋 (반복)

// 방법 1: T0 접점 사용
T0 ──| |──( )── P0020            // T0가 ON일 때 P0020 ON

// 방법 2: 50% 듀티 사이클
P0000 ──| |──[ TON T0 K5 ]──    // 0.5초 ON
T0 ──| |──[ TON T1 K5 ]──       // 0.5초 OFF (T0 완료 후)
T1 ──| |──[RST T0 ]──            // T1 완료 시 T0 리셋 (반복)
T0 ──| |──( )── P0020            // 0.5초 ON, 0.5초 OFF
```

### 3.3 타임차트 해석

PCQ 시험에서는 타임차트를 보고 래더를 작성하는 문제가 출제됩니다.

```
타임차트 예시:

P0000 ──┐     ┌───┐     ┌───┐
        │     │   │     │
        └─────┘   └─────┘
                  3초
P0020 ─────────┐           ┐
               │           │
               └───────────┘
               ↑3초 지연     ↑즉시 OFF

→ 해석: P0000이 ON 되고 3초 후 P0020 ON, P0000이 OFF 되면 즉시 P0020 OFF
→ 래더: TON T0 K30 → T0 접점으로 P0020 출력
```

## 타이머 사용 시 주의사항

| 주의사항 | 설명 |
| --- | --- |
| 단위 확인 | 100ms 기준인지 10ms 기준인지 확인 |
| 리셋 | 입력 OFF 시 자동 리셋 (TON), 필요시 RST 명령어 사용 |
| 정전 유지 | 정전 시 타이머 값 초기화 (래치 영역 설정 시 유지 가능) |
| 중첩 사용 | 같은 타이머를 여러 회로에서 사용하면 오동작 발생 |
| 스캔 타임 | 스캔 타임이 길면 타이머 정밀도 저하 |
