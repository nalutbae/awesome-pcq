# 기본 회로 (Ladder Basics)

> PCQ 시험에 출제되는 필수 기본 회로를 정리합니다.
> 모든 래더 프로그래밍의 기초가 되는 회로입니다.

## 1. A접점과 B접점

### A접점 (Normally Open, 평상시 열림)

```
    입력이 OFF일 때: ──┤ ├──  (열림 → 전류 차단)
    입력이 ON일 때:  ──┤ ├──  (닫힘 → 전류 흐름)
```

- XG5000 단축키: **F3**
- 기호: ──| |──
- 용도: 스위치, 센서 입력 등 (입력이 있을 때 동작)

### B접점 (Normally Closed, 평상시 닫힘)

```
    입력이 OFF일 때: ──┤/├──  (닫힘 → 전류 흐름)
    입력이 ON일 때:  ──┤/├──  (열림 → 전류 차단)
```

- XG5000 단축키: **F4**
- 기호: ──|/|──
- 용도: 정지 버튼, 인터록 등 (입력이 없을 때 동작)

## 2. 코일 출력

- XG5000 단축키: **F9**
- 기호: ──( )──
- 용도: 램프, 모터, 밸브 등 출력 제어

```
P0000 ──| |──( )── P0020

// P0000이 ON 되면 P0020 출력 ON
```

## 3. 자기유지 회로 (Self-Holding Circuit)

> PCQ 시험에서 가장 기본적으로 출제되는 회로입니다.
> 버튼을 누른 후 손을 떼어도 출력이 유지되는 회로입니다.

### 회로도

```
                  P0000 (시작)
P0000 ──| |──┬──( )── P0020 (출력)
              │
P0020 ──| |──┘  (자기유지 접점)
              │
P0001 ──|/|──┘  (정지, B접점)
```

### 래더 로직 (XG5000 형식)

```
// 자기유지 회로
// P0000: 시작 버튼 (A접점)
// P0001: 정지 버튼 (B접점)
// P0020: 출력 (램프/모터)
P0000 ──| |──┬──( )── P0020
P0020 ──| |──┘
P0001 ──|/|──┘
```

### 동작 설명

1. **시작 버튼 P0000 ON**: P0020 코일 ON
2. **P0020 ON → P0020 자기유지 접점 ON**: P0000을 떼어도 P0020 유지
3. **정지 버튼 P0001 ON** (B접점이므로 ON되면 회로 차단): P0020 OFF → 자기유지 해제

### 시뮬레이터 테스트

1. XG5000 시뮬레이터 시작
2. `Ctrl + Enter`로 P0000 강제 ON → P0020 ON 확인
3. P0000 강제 OFF → P0020 유지 확인 (자기유지)
4. P0001 강제 ON → P0020 OFF 확인

## 4. 인터록 회로 (Interlock Circuit)

> 두 출력이 동시에 ON 되지 않도록 보호하는 회로입니다.
> 모터 정역 회전 등에서 필수적으로 사용됩니다.

### 회로도

```
// 정회전 (P0020)과 역회전 (P0021) 인터록
P0000 ──| |──|/|──( )── P0020 (정회전)
         P0021       │
                      │
P0001 ──| |──|/|──( )── P0021 (역회전)
         P0020       │
```

### 래더 로직

```
// 인터록 회로
// P0000: 정회전 버튼
// P0001: 역회전 버튼
// P0020: 정회전 출력
// P0021: 역회전 출력
// P0021의 B접점이 P0020 회로에, P0020의 B접점이 P0021 회로에 직렬로 연결
P0000 ──| |──|/|──( )── P0020
         │    P0021
P0001 ──| |──|/|──( )── P0021
              P0020
```

### 동작 설명

1. P0000 ON → P0020 ON (정회전)
2. P0020이 ON인 상태에서 P0001 ON → P0020의 B접점이 열림 → P0021이 ON 되려면 P0020이 OFF 되어야 함
3. 동시 동작 방지 (하드웨어 보호)

## 5. 플립플롭 회로 (Toggle)

> 하나의 버튼으로 ON/OFF를 토글하는 회로입니다.
> PCQ 기출문제에서 자주 출제됩니다.

### 래더 로직

```
// 플립플롭 회로 (상승 펄스 활용)
// P0000: 토글 버튼
// P0020: 출력
// M0000: 펄스 플래그
P0000 ──↑── M0000     // 상승 펄스: P0000 상승 에지에서 M0000 한 스캔 ON
M0000 ──| |──|/|──( )── P0020   // M0000이 ON이고 P0020이 OFF면 ON
M0000 ──| |──| |──( )── P0020   // M0000이 ON이고 P0020이 ON이면 OFF
```

## 6. 기본 회로 조합

PCQ 실제 문제는 위 기본 회로들을 조합하여 출제됩니다.

| 조합 | 예시 |
| --- | --- |
| 자기유지 + 타이머 | 시작 후 5초 지연 출력 |
| 인터록 + 자기유지 | 정역 회전 + 유지 |
| 플립플롭 + 카운터 | 버튼 누른 횟수만큼 동작 |
| 타이머 + 카운터 | 반복 동작 N회 후 정지 |
