# 필수 명령어 집합 (Instructions)

> PCQ 시험에 출제되는 XG5000 필수 명령어를 정리합니다.

## 기본 접점 명령어

| 명령어 | 단축키 | 기호 | 설명 |
| --- | --- | --- | --- |
| A접점 | F3 | ──\| \|── | 평상시 열림 (Normally Open) |
| B접점 | F4 | ──\|/\|── | 평상시 닫힘 (Normally Closed) |
| 코일 출력 | F9 | ──( )── | 출력 코일 |
| 부정 코일 | — | ──(/)── | 부정 출력 (입력 반전) |

## 펄스 명령어

> PCQ 기출문제에서 자주 출제되는 펄스 검출 명령어입니다.

| 명령어 | 기호 | 설명 |
| --- | --- | --- |
| 상승 펄스 | ──↑── | 입력 상승 에지에서 1스캔 ON |
| 하강 펄스 | ──↓── | 입력 하강 에지에서 1스캔 ON |

### 상승 펄스 (Rising Edge)

```
// P0000이 OFF→ON 전환 순간에 1스캔 동안만 M0000 ON
P0000 ──↑──( )── M0000

// 활용: 버튼 한 번 누름을 1회 펄스로 변환
// (버튼을 누르고 있는 동안 여러 번 동작하는 것 방지)
```

### 하강 펄스 (Falling Edge)

```
// P0000이 ON→OFF 전환 순간에 1스캔 동안만 M0001 ON
P0000 ──↓──( )── M0001

// 활용: 버튼에서 손을 뗀 순간 동작
```

## 응용 명령어 (F10)

> F10 단축키로 입력하는 응용 명령어들입니다.

### SET / RST (설정 / 리셋)

| 명령어 | 형식 | 설명 |
| --- | --- | --- |
| SET | `[SET P0020]` | 지정 디바이스를 ON 후 유지 |
| RST | `[RST T0]` | 지정 디바이스 리셋 (OFF 또는 0) |

```
// SET/RST 예제
P0000 ──| |──[ SET P0020 ]──     // P0000 ON 시 P0020 ON 유지
P0001 ──| |──[ RST P0020 ]──     // P0001 ON 시 P0020 OFF
```

### MOV (데이터 이동)

| 명령어 | 형식 | 설명 |
| --- | --- | --- |
| MOV | `[MOV D0 D10]` | D0의 값을 D10으로 이동 |

```
// MOV 예제: P0000이 ON 되면 상수 100을 D0에 저장
P0000 ──| |──[ MOV K100 D0 ]──    // K100 → D0

// 활용: 카운터 설정값 변경
P0000 ──| |──[ MOV K5 D100 ]──   // D100 = 5
P0001 ──| |──[ MOV K10 D100 ]──  // D100 = 10 (설정값 변경)
```

### 비교 명령어

| 연산자 | 명령어 | 설명 |
| --- | --- | --- |
| = | `[ D0 == K5 ]` | D0가 5와 같은가? |
| ≠ | `[ D0 != K5 ]` | D0가 5와 다른가? |
| > | `[ D0 > K5 ]` | D0가 5보다 큰가? |
| < | `[ D0 < K5 ]` | D0가 5보다 작은가? |
| >= | `[ D0 >= K5 ]` | D0가 5보다 크거나 같은가? |
| <= | `[ D0 <= K5 ]` | D0가 5보다 작거나 같은가? |

```
// 비교 명령어 예제
// D0가 10과 같을 때 P0020 ON
D0 == K10 ──────( )── P0020

// C0가 5보다 크거나 같을 때 P0021 ON
C0 >= K5 ──────( )── P0021
```

### 사칙연산 명령어

| 명령어 | 형식 | 설명 |
| --- | --- | --- |
| ADD | `[ADD D0 D1 D2]` | D2 = D0 + D1 |
| SUB | `[SUB D0 D1 D2]` | D2 = D0 - D1 |
| MUL | `[MUL D0 D1 D2]` | D2 = D0 × D1 |
| DIV | `[DIV D0 D1 D2]` | D2 = D0 ÷ D1 |

```
// ADD 예제: D0와 D1의 합을 D2에 저장
P0000 ──| |──[ ADD D0 D1 D2 ]──
```

### 증감 명령어

| 명령어 | 형식 | 설명 |
| --- | --- | --- |
| INC | `[INC D0]` | D0 = D0 + 1 |
| DEC | `[DEC D0]` | D0 = D0 - 1 |

```
// INC 예제: P0000 상승 에지마다 D0 1씩 증가
P0000 ──↑──[ INC D0 ]──
```

## 디바이스 (Device) 정리

| 디바이스 | 기호 | 범위 | 용도 |
| --- | --- | --- | --- |
| 입출력 | P | P0000~ | 물리적 입출력 (I/O) |
| 내부 릴레이 | M | M0000~ | 내부 보조 릴레이 |
| 타이머 | T | T0~T511 | 타이머 |
| 카운터 | C | C0~C255 | 카운터 |
| 데이터 레지스터 | D | D0~ | 데이터 저장 (16비트) |
| 상수 | K | K값 | 10진수 상수 |
